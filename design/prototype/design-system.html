09 — Usage rules

Rules that keep every page consistent

These rules are fixed across the Warm Pearl, Action-led and layout directions selected in this round.

Coral

Clean Coral carries the brand; solid CTAs use Action Coral with white text.

White surfaces

White cards sit on Warm Pearl or grey canvases to create contrast.

Text

Dark charcoal is used on white or light grey only, never on coral.

Depth

Use borders, spacing and alternating surfaces. Never use shadows.

Mobile

Multi-column patterns collapse to one column with 16px gutters.

Motion

Buttons start plain; the corner bloom sweeps across only while hovered. FAQs use 560ms motion.

Icons

Use the Hugeicons stroke-rounded library at consistent 18–24px UI sizes.

Content

Headings stay short; long SEO copy uses a 760px reading column.
